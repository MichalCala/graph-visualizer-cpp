# Graph Visualizer

An interactive graph algorithm visualizer written in C++.

## Features

- Directed and undirected graphs
- Adjacency matrix representation
- Depth-First Search (DFS)

## Technologies

- C++17
- CMake
- Ninja

## Build and run

```bash
cmake -S . -B build -G Ninja
cmake --build build
./build/graph_visualizer.exe
```
